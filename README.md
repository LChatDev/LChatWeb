> LChat был полностью создан с помощью ИИ и использует сторонние компоненты. / LChat was created entirely with AI assistance and uses third-party components.

Веб-часть LChat: страницы, стили, клиентские скрипты и PHP-шлюз. Для сообщений, файлов, сессий и звонков необходим отдельный [LChatHost](https://github.com/LChatDev/LChatHost). Инструкция: [русский](doc_RU.md) · [English](doc_EN.md).

LChat's web frontend and PHP gateway. A separate [LChatHost](https://github.com/LChatDev/LChatHost) handles sessions, messages, files and call signaling. Guides: [русский](doc_RU.md) · [English](doc_EN.md).

Источник компонентов интерфейса указан в [TELEGRAM_SOURCE.md](TELEGRAM_SOURCE.md). Лицензия / License: [GPL-3.0](LICENSE).
