# Установка LChatWeb

LChatWeb отдаёт страницы и безопасно передаёт запросы серверной части [LChatHost](https://github.com/leosmleol-svg/LChatHost). База и загруженные файлы хранятся на LChatHost. Серверная часть может находиться на том же сервере сайта или на другом хосте/ПК, доступном по HTTPS. Версии LChatWeb и LChatHost должны быть совместимы.

1. Настройте LChatHost по [инструкции](https://github.com/leosmleol-svg/LChatHost/blob/main/doc_RU.md), включая MySQL, публичный HTTPS и случайные `install_key` и `proxy_secret`. В конфиге LChatHost укажите публичный адрес LChatWeb в `public_url`.
2. На веб-хостинге нужны PHP 8.2+ с `curl`, Apache с `mod_rewrite`, применение `.htaccess` и доверенный HTTPS. Загрузите файлы этого проекта в одну отдельную папку, сохраняя скрытые файлы. Убедитесь, что `config.php`, `gateway.php` и `apis/` закрыты от прямого доступа.
3. Скопируйте `config.example.php` в `config.php`. Укажите доверенный HTTPS-адрес LChatHost и **тот же** случайный `proxy_secret`, который указан на нём:

   ```php
   'backend' => ['mode' => 'pc', 'url' => 'https://backend.example.com/', 'proxy_secret' => 'ВАШ_ОБЩИЙ_СЛУЧАЙНЫЙ_СЕКРЕТ'],
   ```

   Секрет должен содержать минимум 32 символа без пробелов; храните оба конфига закрыто. `pc` — имя режима шлюза и подходит как для ПК, так и для другого хостинга. HTTP и самоподписанные сертификаты не поддерживаются. LChatWeb должен иметь возможность исходящих HTTPS-подключений к LChatHost.
4. Откройте `https://ваш-сайт/install.php`, введите ключ LChatHost и создайте таблицы. Зарегистрируйте владельца `leosmleol`, удалите установщик из обеих копий и очистите `install_key` на LChatHost. Проверьте вход, сообщения, загрузку файла и звонки.

Админка и её форма настроек отображаются LChatWeb; права и значения проверяются на LChatHost. Владелец может менять название, регистрацию, лимит звонков и TURN. В примере LChatHost указан сервер владельца `turn:209.25.141.16:45209?transport=tcp`: его секрет нужно задать отдельно на LChatHost, в репозитории его нет. Если серверная часть выключена, страница может открыться, но приложение не сможет работать. Прямой доступ к публичному backend тоже возможен: защищайте сервер и не раскрывайте секреты. Для связи пользователей из разных сетей может понадобиться отдельный [TURN](https://github.com/leosmleol-svg/LChatRU/blob/main/CALLS.md); HTTPS-шлюз не заменяет его.

Перед обновлением сохраните оба конфига, базу, `data/` и `files/`. GitHub Pages не поддерживает PHP. Сквозные тесты выполнялись локально, развёртывание на реальном хостинге не проверено.
