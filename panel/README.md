# Панель LChatWeb

Панель открывается в браузере на `127.0.0.1`. Она проверяет HTTPS и общий секрет на LChatHost и сохраняет `config.php` в выбранной папке LChatWeb.

1. Распакуйте LChatWeb в отдельную папку и настройте [LChatHost](https://github.com/LChatDev/LChatHost/blob/main/doc_RU.md).
2. Скачайте [панель для Windows или Linux](https://github.com/LChatDev/LChatWeb/releases/tag/web-panel-v1.0.1). Откройте терминал в папке LChatWeb и запустите панель. На Linux разрешите запуск файла через `chmod +x LChatWeb-panel-linux-amd64`.
3. Если запускаете из другой папки, передайте `--root` и путь к папке LChatWeb. Панель откроет браузер. С `--no-browser` она выведет адрес в терминал.
4. Введите HTTPS-адрес LChatHost и тот же `proxy_secret`, который задан на хосте. Нажмите **Проверить и сохранить**. Для изменения существующего конфига поставьте галочку замены.
5. Разместите LChatWeb с этим конфигом на PHP-хостинге. Откройте `install.php` на сайте и завершите [установку](../doc_RU.md).

В закрытой сети с собственным CA можно указать панели `--ca-file путь.pem`. PHP на сервере LChatWeb тоже должен доверять этому CA. Для обычного публичного сертификата этот параметр не нужен.

Сборка из исходников в каталоге `panel` выполняется командой `go build -o LChatWeb-panel main.go`. Для Windows используйте имя файла с расширением `.exe`.
